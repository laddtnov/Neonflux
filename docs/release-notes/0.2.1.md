Nothing about the theme looks different. Two CSS features are swapped for
equivalents that Obsidian's theme linter does not flag as only partially
supported.

## What changed

**Custom task states no longer use CSS masking.** Obsidian draws the checkbox
tick as a pseudo-element clipped by a mask, so a state like `- [/]` had to
cancel that mask or its character would be clipped to a checkmark shape. The
theme now removes the pseudo-element instead, and draws the character in the
one Obsidian does not touch. Same result, no masking properties.

**Print break hints use the CSS 2.1 spellings.** `page-break-after` and
`page-break-inside` rather than `break-after` and `break-inside`. Identical
behaviour in the engine Obsidian runs on, and the older pair is the
conventional one for paged media.

## What this costs you

Nothing. Both changes were re-rendered against Obsidian's own stylesheet
before shipping: all six task states are pixel-identical to 0.2.0 in normal
rendering, and identical again in high-contrast mode. The print stylesheet
still avoids stranding a heading at the foot of a page.

If you are on 0.2.0 and everything looks right, it still will.

## Install

Download `theme.css` and `manifest.json` below into
`YourVault/.obsidian/themes/Neonflux/`, then Settings → Appearance → Themes.

Already installed from the community list? Obsidian updates it for you.
