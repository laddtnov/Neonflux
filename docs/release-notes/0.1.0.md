First release of Neonflux — a cyberpunk theme for Obsidian.

Neon on near-black, Orbitron headings over a `>_` prompt, and a light mode
that is not an afterthought. Built by remapping Obsidian's own design tokens
rather than overriding its rules, so it reaches community plugins and survives
app updates. Zero JavaScript.

## Install

Manual, until it lands in the community themes list:

1. Download `theme.css` and `manifest.json` below.
2. Put both in `YourVault/.obsidian/themes/Neonflux/`.
3. Settings → Appearance → Themes → Neonflux.

## Built for reading, not for screenshots

A note-taking app is read for hours, so the palette is deliberately restrained
where it counts:

- Accents live on short strings — headings, links, chrome, code tokens. Body
  text is a calm near-white.
- Glow is applied to `h1` and `h2` only. Never to text you read at length.
- Contrast is enforced by a checker over both themes, with **muted text and
  syntax-highlight colours held to the 4.5:1 text floor**, not the 3.0
  non-text one. A code comment is text somebody parses.
- Form controls get their own higher-contrast border token, because on a text
  field or checkbox the border *is* the affordance (WCAG 1.4.11).

## Fonts

Six faces are embedded as base64 woff2 — nothing is fetched at launch, so
there is no CDN call, no IP leak, and no startup stall offline.

| Role | Latin | Cyrillic |
| --- | --- | --- |
| Headings | Orbitron | Unbounded |
| Body and UI | Rajdhani | Exo 2 |
| Code | Share Tech Mono | JetBrains Mono |

The three Latin faces have no Cyrillic at all, so each is paired with a
companion. Font fallback is per-glyph, so a mixed Latin/Ukrainian note renders
correctly with no `unicode-range` rules — verified by measuring glyph widths
against the generic fallback, not by trusting `document.fonts.check()`.

## Known limitations

Documented honestly in [ACCESSIBILITY.md](https://github.com/laddtnov/Neonflux/blob/main/ACCESSIBILITY.md):

- The `>_` before each H1 is CSS generated content, which screen readers
  announce. There is no reliable way to suppress that.
- Rajdhani is a display face doing a text face's job — condensed, low
  x-height. A deliberate trade for the aesthetic; override the text font in
  Settings if you feel it.
- Tested on macOS in Obsidian 1.13.7, dark and light, Reading view and Live
  Preview. Not yet tested on Windows, Linux, mobile, print, or with a screen
  reader.
