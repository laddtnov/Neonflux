A smaller download. Nothing about the theme looks different.

`theme.css` drops from **189KB to 124KB** — Obsidian's review flags a theme
file this large, and the file was almost entirely font data: the authored
stylesheet is 18KB of it.

## What changed

The embedded fonts now carry their **base subsets only**. The `-ext` subsets
were 64KB of glyphs almost nobody types in a note — `cyrillic-ext` is Church
Slavonic, Abkhaz and historic letterforms; `latin-ext` is Central-European and
Turkish diacritics. Fourteen embedded faces became eight.

Not one style rule changed. `src/theme.css` is byte-identical to 0.1.0, so
every colour, heading, callout and code block renders exactly as before, in
both themes.

## What this costs you

If you write in Polish, Czech, Hungarian, Turkish, Romanian — or in Church
Slavonic — a handful of accented characters (`ł`, `ř`, `ğ`, `ș`, `ő`) now come
from your system font instead of Rajdhani. Font fallback is per-glyph, so this
is one character in a different face, not a paragraph that changes shape.

English, Ukrainian and Russian are fully covered by the base subsets and look
identical to 0.1.0. So do `ö`, `ß`, `ñ` and `ç` — those live in the base
`latin` subset.

If this trade is wrong for you, say so in an issue. Re-adding a subset is one
line in the build script.

## Install

Same as before. Download `theme.css` and `manifest.json` below into
`YourVault/.obsidian/themes/Neonflux/`, then Settings → Appearance → Themes.

Already installed from the community list? Obsidian updates it for you.
